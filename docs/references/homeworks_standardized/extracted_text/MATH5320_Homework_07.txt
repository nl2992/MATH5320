Merton Model refers to a structural model, that generally assumes that a firm’s asset value follows a 
process and defaults if the asset value gets too low relative to the debt, i.e. 𝑉𝑡 < 𝐷.  It’s called 
structural because it is based off a balance-sheet structure, and also, under the basic Merton model, 
there is no default before maturity (at T), and at t=0, the instantaneous default probability is zero.  
It models the assets like the following: 
𝑑𝑉 =  𝜇𝑉 𝑑𝑡 +  𝜎𝑉 𝑑𝑊  
Recall from 5264, the solution to that is: 
𝑉𝑇 = 𝑉0𝑒𝑥𝑝((𝜇 − 𝜎2/2))𝑇 + 𝜎𝑊𝑇)  
And the only debt that is modelled is through a ZCB of value B, and is only checked for default at T. 
IT functions effectively in a way where equity is a call option on the assets with strike B, and the debt 
is a such that it is ZCB – put on the assets.

Now, we look at the previous problem which was done with log-returns, and now we note the

from the portfolio price series or reconstructed from AAPL and CAT price changes, because the 
portfolio dollar change satisfies: 
 
Δ𝑃 = 𝑁𝐴𝐴𝑃𝐿 ∗ Δ𝐴 + 𝑁𝐶𝐴𝑇 ∗ Δ𝐶 
 
This is linear in the component changes, so constructing the portfolio scenario-by-scenario from A 
and C gives an algebraically identical result to using the portfolio price series directly. This contrasts

𝑟𝑃 ≠ 𝑁AAPL ∗ 𝑟𝐴 + 𝑁CAT ∗ 𝑟𝐶 
The correct first-order approximation is 𝑟𝑃 ≈ ∑𝑤𝑖𝑟𝑖, and needs to account for Jensen’s inequality
