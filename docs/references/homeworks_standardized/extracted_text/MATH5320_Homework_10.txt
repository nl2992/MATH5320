d)   
From the previous parts, the put is repriced in a downside scenario with stock and time 
changed, the the IV remains fixed, so the tail put value becomes: 


𝑃0.01 = 𝑃(𝑆0.01, 𝐾, 𝑟, 𝜎imp, 𝑇rem). 
 
If volatility risk is allowed, then instead the put value is 
𝑃0.01 = 𝑃(𝑆0.01, 𝐾, 𝑟, 𝜎0.01, 𝑇rem), 
 
where 𝜎0.01 can move with the market. So the risk will now materially differ, since we may 
either be under or over-hedged, and the error term is driven by vega. This is because the put 
value now depend on the second state variable σ, in addition to 𝑆. Gamma is still important, 
for the stock-direction nonlinearity of the put, but the incremental error from allowing IV to 
move is mainly a volatility-sensitivity effect rather than a pure gamma effect. 
This means that the VaR calculation is changed in a material fashion, sicne the option hedge 
is now exposed to both the downside stock move and the associated vol move. Since we 
know that a long put has positive vega, an increase in IV will raise the put value and improve 
the hedge, whenever the stock portfolio is losing money. In equity markets, downside stock 
moves tend to be associated with higher IV, so allowing σ to rise in the left tail, will naturally 
make the hedge more effective that fixing the volatility. The Fixed IV calculation ,as a result, 
is likely more conservative w.r.t to the protective value of the put in stressed downside 
scenarios. 
 
 
We built a sensitivity table, where we note that with no vol bump, the tail implied volatility 
remains 0.1767, the tail put value is 182.95, and the hedged VaR with 1 percent liquidation is 
$377,696.10.  
Wherein, if the tail implied probability volatility is bumped upward by 1 vol point (1 bp) the 
tail put value rises to 190.80, and the hedged VaR falls to about $372,144.74. For a 5 vol 
bump, the VaR falls to $349K-ish. Hence the directional idea showcases that a higher tail 
implied volatility increases the value of the protective put and lowers the portfolio’s hedged 
VaR. 
 


 
Noting it in this diagram above, it shows that it scales almost linearly over the small bump 
range, although, in a fuller model, the relationship is probably not exactly linear, as under 
BSM, option values are non-linear in volatility, and neither would it be in other models like 
Heston.  
So resultingly, we know that once volatility risk is incorporated, the hedge gains an additional 
source of protection via Vega. As a result, the VaR computed in previous parts will generally 
be overstated relative to a more realistic joint stock volatility model. Conclusively if 
downside equity moves, are accompanied by a vol spike (which it does, usually – consider 
VIX during Covid cash), then fewer puts will be needed to achieve the same target VaR 
reduction.
