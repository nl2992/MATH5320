8. Interpretation
The earlier SPX-based notebook was not the correct setup for this question. The
correct HW10 Q1 setup uses the HW9/Q9 AAPL-CAT portfolio framework.
The expected exception count is approximately 1% of the number of usable backtest
dates because the VaR confidence level is 99%.
The direct GBM backtest results show that the realised exception counts are above
the expected counts for several long positions. This suggests that the 5-year GBM
VaR is not fully capturing downside tail risk for AAPL, CAT, and the fixed-share
portfolio during this sample.
The short-position exception counts are closer to the expected count than the long-
position counts, although CAT and P still show more exceptions than expected under
the direct method.
For P, the direct-P and component Monte Carlo methods produce similar but not
identical results. This is expected because direct P treats the portfolio value itself as
one GBM process, while the component method models AAPL and CAT separately
and preserves the fixed-share portfolio structure through simulation.
